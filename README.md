# I.G.R.I.S.

### Integrated Guardian Responsive Intelligence System

I.G.R.I.S. is a personal AI desktop assistant project designed to provide a voice-controlled interface with a futuristic HUD-style visual experience.

## 🚀 Features

* 🎙️ Voice-based interaction
* 🔊 Voice command processing
* 🧠 Command handling and response system
* 🌌 Futuristic hologram-style interface
* 🖥️ Desktop-based assistant experience
* ▶️ Windows batch-file launcher

## 🛠️ Technologies Used

* Python
* JavaScript
* HTML
* CSS
* Git & GitHub

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the Windows batch file:

```text
start_igris_listener.bat
```

4. Follow the assistant's voice interaction flow.

## 🎯 Project Goal

The goal of I.G.R.I.S. is to develop a personal AI assistant that combines voice interaction, intelligent command processing, and an immersive visual interface.

This project is being developed incrementally, with future versions planned to expand its capabilities.
